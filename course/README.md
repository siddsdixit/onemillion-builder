# OneMillion Builder Course

**18 days. One phase at a time. A real product, shipped.**

This is not a video course. This is not a tutorial. This is a structured build.

Every day, you use a real agent to do real work on a real product. By Day 18, you have something deployed and live — not a toy, not a demo, not a tutorial project.

## How It Works

- **20 minutes per day.** Read the lesson, run the agent, verify the output.
- **One agent per phase.** Each day masters one tool in the pipeline.
- **Self-referential.** The agents help you understand themselves. Ask the ASK agent about how the BUILD agent works. Use the IDEA agent on a meta-product about OneMillion.
- **Your product, not a tutorial project.** Pick something you actually want to build on Day 3 and build it the whole way through.

## Course Days

| Phase | Days | Agent | Output |
|-------|------|-------|--------|
| Setup | 1-2 | — | Claude Code running, agents installed |
| IDEA | 3-4 | `idea` | `prd.md` — your product vision |
| SPEC | 5-6 | `spec`, `validate-spec` | `refined-prd.md` — engineering requirements |
| DESIGN | 7-8 | `design` | Design system, screens, seed data |
| PLAN | 9-10 | `plan`, `validate-plan` | Architecture + sprint briefs |
| BUILD | 11-14 | `build` | Working code, 4 sprints |
| TEST | 15 | `test` | Test suite, E2E, accessibility |
| GUARD | 16 | `guard` | Security audit |
| SHIP | 17 | `ship` | Live URL |
| SELL | 18 | `sell` | Marketing, SEO, launch |

## The Assignment System

Each day has:
- **Learn** (5 min) — concept for the day
- **Do** (10 min) — run the agent, verify output
- **Reflect** (5 min) — assignment question to answer in your build journal

Keep a build journal. One paragraph per day. On Day 18 you'll have an origin story for your product.
